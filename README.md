## 📖 About Repository

This repository contains a comprehensive collection of projects developed during **Spring Batch 54 & 55 Training**. The projects cover Java fundamentals, JDBC, Spring Core, Spring MVC, Design Patterns, and practical laboratory exercises.

The goal of this repository is to provide hands-on experience in building enterprise-level Java applications using industry-standard technologies.

## 🚀 Getting Started

### 1️⃣ Clone Repository

```bash
git clone https://github.com/rajbalakumari/Spring-Batch-54-And-55.git
```

### 2️⃣ Import Project

- Open Eclipse IDE
- Import Existing Maven Project

### 3️⃣ Configure Database

Update database credentials according to your local setup.

### 4️⃣ Build Project

```bash
mvn clean install
```

### 5️⃣ Run Application

Deploy the project on Apache Tomcat Server.

### 6️⃣ Access Application

```text
http://localhost:8080/project-name/
```
